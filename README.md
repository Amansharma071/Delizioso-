# Delizioso Restaurant Website

A modern and elegant restaurant landing page built with HTML, CSS, and JavaScript. This project showcases a premium dining experience with sections for hero content, services, story, special dishes, menu highlights, testimonials, and online reservations.

## Features

- Responsive restaurant landing page
- Elegant hero slider with CTA buttons
- Services, story, menu, and reservation sections
- Special dish showcase and pricing cards
- Testimonials and event highlight sections
- Clean, premium design inspired by modern food brands

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts / Ionicons
